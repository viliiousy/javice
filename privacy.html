개인정보처리방침

시행일 2026년 8월 24일 · 최종 수정 2026년 8월 24일

자비스(이하 "본 서비스", bashy.app)는 개인이 만들어 운영하는 무료 개인 일정·습관 관리 대시보드입니다. 본 방침은 본 서비스가 어떤 정보를 어떻게 다루는지 설명합니다.

요약 — 본 서비스는 이용자의 데이터를 판매하지 않으며, 광고에 사용하지 않고, 광고 목적으로 제3자에게 제공하지 않습니다. 구글 계정 데이터는 이용자 본인에게 기능을 제공하기 위해서만 사용됩니다.

1. 수집·이용하는 정보

1.1 구글 계정을 통해 접근하는 정보

이용자가 구글 로그인 시 아래 권한에 동의한 경우에만 해당 정보에 접근합니다.

구글 권한 범위접근하는 정보사용 목적
auth/calendar캘린더 목록, 일정의 제목·시간·설명·장소대시보드와 달력에 일정 표시. 앱에서 만든 일정의 생성·삭제
auth/tasks할일 목록과 각 할일의 제목·기한·완료 여부·메모할일 표시 및 추가·수정·완료·삭제
userinfo.profile이름, 프로필 사진화면 상단에 표시
userinfo.email이메일 주소계정 식별 및 계정별 데이터 분리

본 서비스는 위 범위 외의 구글 데이터(메일, 드라이브 파일, 연락처 등)에 접근하지 않습니다.

1.2 이용자가 직접 입력하는 정보

  • 습관 항목과 체크 기록
  • 식단 기록 (음식명, 칼로리, 영양소)
  • 운동 기록, 체크리스트, 메모
  • 인바디 기록 (체중, 근육량, 체지방률, 기초대사량)

1.3 기기·기술 정보

  • 푸시 알림 토큰 (알림 기능을 켠 경우)
  • 다크 모드, 알림 시간 등 화면 설정값

본 서비스는 접속 로그를 별도로 수집하거나 분석 도구로 이용자를 추적하지 않습니다.

2. 정보의 저장 위치

  • 이용자 브라우저(localStorage) — 오프라인에서도 쓸 수 있도록 기기에 저장됩니다.
  • Firebase Realtime Database (Google Cloud, 아시아 남동부 리전) — 기기 간 동기화를 위해 저장되며, 구글 계정 식별자별로 분리된 경로에 보관됩니다.

모든 통신은 HTTPS로 암호화됩니다.

3. 제3자 전송

본 서비스는 아래의 경우에 한해 외부 서비스와 통신합니다.

AI 비서 기능 (Groq) — 이 기능은 이용자가 설정에서 본인의 Groq API 키를 직접 입력한 경우에만 동작하며, 기본값은 꺼져 있습니다.

활성화한 경우, 이용자가 AI 비서에게 질문할 때 아래 정보가 api.groq.com으로 전송됩니다: 오늘 일정의 제목과 시간, 미완료 할일의 제목과 기한, 습관 이름과 완료 여부, 식단 칼로리 요약, 체크리스트·메모 제목, 이용자가 입력한 메시지. 음식 사진 분석을 사용하면 해당 사진도 전송됩니다.

AI 비서를 쓰지 않거나 API 키를 입력하지 않으면 구글 데이터는 Groq로 전송되지 않습니다. 이 기능을 끄려면 설정에서 API 키를 비워두면 됩니다.

  • Open-Meteo — 날씨 표시를 위해 위도·경도만 전송합니다. 개인 식별 정보는 포함되지 않습니다.
  • ipapi.co — 위치를 자동 추정하는 경우에 한해 이용자의 IP 주소가 전송됩니다.
  • Firebase Cloud Messaging / Telegram — 이용자가 켠 알림을 발송하기 위해 사용됩니다.

이 외에 이용자 데이터를 제3자에게 판매·대여·양도하지 않습니다. 법령에 따른 적법한 요구가 있는 경우에만 예외적으로 제공될 수 있습니다.

4. 구글 사용자 데이터 정책 준수

자비스가 구글 API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 Limited Use requirements를 포함한 Google API Services User Data Policy를 준수합니다.

구체적으로, 본 서비스는 구글 사용자 데이터를 (가) 이용자에게 보이는 기능을 제공하는 목적으로만 사용하고, (나) 광고 목적으로 사용하거나 판매하지 않으며, (다) 일반화된 AI/ML 모델의 학습에 사용하지 않고, (라) 사람이 열람하지 않습니다. 다만 이용자가 명시적으로 동의했거나, 보안 목적, 법령 준수를 위해 필요한 경우는 예외입니다.

5. 보관 기간과 삭제

  • 데이터는 이용자가 삭제하거나 계정 삭제를 요청할 때까지 보관됩니다.
  • 기기에서 삭제 — 앱에서 로그아웃하면 해당 브라우저에 저장된 데이터가 지워집니다.
  • 구글 권한 철회 — myaccount.google.com/permissions에서 자비스의 액세스 권한을 삭제하면 즉시 구글 데이터 접근이 중단됩니다.
  • 서버 데이터 완전 삭제 — 아래 이메일로 요청하시면 Firebase에 저장된 해당 계정의 데이터를 삭제해 드립니다.

6. 이용자의 권리

이용자는 언제든지 본인 데이터의 열람·정정·삭제·처리 정지를 요청할 수 있으며, 구글 권한 동의를 철회할 수 있습니다.

7. 아동의 개인정보

본 서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 알면서 수집하지 않습니다.

8. 방침의 변경

본 방침이 변경되는 경우 이 페이지에 수정된 내용과 시행일을 게시합니다. 중요한 변경이 있을 경우 앱 내에서 안내합니다.

Jarvis ("the Service", bashy.app) is a free personal schedule and habit dashboard built and operated by an individual developer. This policy explains what information the Service handles and how.

Summary — The Service does not sell your data, does not use it for advertising, and does not share it with third parties for advertising purposes. Google account data is used solely to provide features to you, the user.

1. Information We Access

1.1 Google account data

The Service accesses the following only if you grant the corresponding permission during Google sign-in.

Google scopeData accessedPurpose
auth/calendarCalendar list; event title, time, description, locationDisplay events on the dashboard and calendar; create and delete events you make in the app
auth/tasksTask lists; task title, due date, status, notesDisplay tasks and let you add, edit, complete and delete them
userinfo.profileName, profile pictureShown in the app header
userinfo.emailEmail addressIdentify the account and keep each user's data separate

The Service does not access any other Google data such as Gmail, Drive files, or Contacts.

1.2 Information you enter

  • Habits and daily check records
  • Meal logs (food names, calories, macros)
  • Workout logs, checklists, notes
  • Body composition records (weight, muscle mass, body fat percentage, BMR)

1.3 Device and technical information

  • Push notification token, if you enable notifications
  • Preferences such as dark mode and notification times

The Service does not collect separate access logs and does not track users with analytics tools.

2. Where Data Is Stored

  • Your browser (localStorage) — stored on your device so the app works offline.
  • Firebase Realtime Database (Google Cloud, Asia Southeast region) — used for cross-device sync, stored under a path scoped to your Google account identifier.

All communication is encrypted over HTTPS.

3. Third-Party Transfers

The Service communicates with external services only in the following cases.

AI assistant (Groq) — This feature works only if you enter your own Groq API key in settings. It is off by default.

When enabled, asking the AI assistant a question sends the following to api.groq.com: titles and times of today's events, titles and due dates of pending tasks, habit names and completion status, a calorie summary, checklist and note titles, and the message you typed. If you use food photo analysis, the photo is also sent.

If you do not use the AI assistant or do not enter an API key, no Google data is sent to Groq. To disable it, clear the API key in settings.

  • Open-Meteo — receives only latitude and longitude to show weather. No personally identifying information is included.
  • ipapi.co — receives your IP address only when location is estimated automatically.
  • Firebase Cloud Messaging / Telegram — used to deliver notifications you have turned on.

We do not otherwise sell, rent, or transfer user data to third parties. Disclosure may occur only where required by applicable law.

4. Compliance with Google API Services User Data Policy

Jarvis's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Specifically, the Service (a) uses Google user data only to provide or improve user-facing features, (b) does not use it for advertising and does not sell it, (c) does not use it to develop, improve, or train generalized AI and/or ML models, and (d) does not allow humans to read it — except with your explicit consent, for security purposes, or to comply with applicable law.

5. Retention and Deletion

  • Data is retained until you delete it or request account deletion.
  • Delete on device — signing out of the app clears the data stored in that browser.
  • Revoke Google access — remove Jarvis at myaccount.google.com/permissions to immediately stop all Google data access.
  • Delete server data — email the address below and the data stored in Firebase for your account will be deleted.

6. Your Rights

You may request access to, correction of, deletion of, or suspension of processing of your data at any time, and you may withdraw your Google permission grant at any time.

7. Children's Privacy

The Service is not directed to children under 14 and does not knowingly collect personal information from children.

8. Changes to This Policy

If this policy changes, the revised text and its effective date will be posted on this page. Material changes will also be announced in the app.

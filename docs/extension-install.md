# Bashy 사용량 수집 확장 설치 (PC 크롬)

Bashy 상단의 AI 사용량 고리(Claude · ChatGPT · Higgsfield)는 이 확장이 채웁니다.

## 왜 확장이 필요한가요
세 서비스는 "남은 사용량"을 API로 알려 주지 않습니다. 그래서 PC 크롬에 로그인된 사이트에서 확장이 5분마다 남은 양을 읽어 Bashy로 보냅니다.

| 서비스 | 읽는 것 | 조건 |
|---|---|---|
| Claude (claude.ai) | 5시간 · 7일 한도 남은 % | claude.ai 에 로그인 |
| ChatGPT (chatgpt.com) | 5시간 · 7일 한도 남은 % | chatgpt.com 에 로그인 |
| Higgsfield | 남은 크레딧 | higgsfield.ai 탭이 열려 있을 때 |
| Gemini · Grok | 아직 못 읽음 | 사이트에 남은 사용량 표시가 없음 |

AI 비서(답하기)에는 이 확장이 필요 없습니다. 사용량 표시에만 씁니다.

## 설치 (약 2분)
1. https://bashy.app/extension.html 에서 **확장 내려받기**를 누르고 받은 ZIP 의 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 엽니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다** → 압축 푼 `bashy-extension` 폴더를 고릅니다.
5. 같은 크롬에서 **bashy.app** 에 로그인합니다. 연결 코드를 넣을 필요 없이 계정에 저절로 연결됩니다.
6. 확장 아이콘(퍼즐 모양 → Bashy 사용량 수집기)을 누르고 **지금 수집**을 누르면 바로 반영됩니다.

## 업데이트
새 버전을 받으면 같은 폴더에 덮어쓴 뒤 `chrome://extensions` 에서 확장의 새로 고침(↻)을 누릅니다.

## 개인정보
확장은 위 세 사이트의 사용량 숫자만 읽고, 대화 내용은 읽거나 보내지 않습니다. 보내는 곳은 bashy.app 하나뿐입니다.
